# exploded-view · Product Exploded View

A brandless rangefinder camera pulls apart along its assembly axes, dives into two macro shots (aperture blades, circuit board) and then reassembles layer by layer. The look is Blender EEVEE with procedurally modelled lens groups, a 9-blade aperture, a focal-plane shutter and a PCB with about 390 SMD parts textured from a generated layout, plus Pillow leader-line labels that follow 3D anchors. Stack: Blender 5.2, Python, numpy, Pillow.

```bash
./render.sh <work_dir>
python3 <skill>/scripts/deliver.py --frames <work_dir>/frames --out clip.mp4
```

Needs Blender 5.2 on PATH, Python 3.9+, numpy, Pillow, ffmpeg, and the macOS system fonts Hiragino Sans GB and Avenir Next.

# S29 产品爆炸拆解 · B「无品牌旁轴数码相机」（v2 精细建模重做）

## 内容
与 A（键盘）不同的新内容：一台无品牌旁轴相机沿装配轴拆开，中途推进到两处微距，再一层一层装回。

| 时间 | 动作 |
|---|---|
| 0–1 s | 整机 3/4 中景：镀铬顶/底盖、皮纹前壳、取景/测距窗、滚花速度盘、快门钮、回卷钮、热靴、镜头 |
| 0.55–2.8 s | 底盖四颗螺丝旋出 → 顶盖上、底盖下、后壳向后 → 主板/感光板螺丝旋出 → 前壳向前 → 十组镜头沿光轴向前依次分层 → 主板、感光板、快门沿光轴向后；软排线随板间距实时拉伸弯折；镜头后拉到侧面全景；标注 01 镜头组 / 02 快门 / 03 感光元件 |
| 2.7–3.05 s | 焦平面快门四片叶片向上收起，露出感光元件 |
| 3.5–4.35 s | **微距 1**：推到光圈组正面，九片叶片收拢到小光孔再张开到半开，透过光孔看到后方感光元件；光圈环同步转动；标注 04 光圈叶片 |
| 4.35–4.9 s | 从镜头前方拉远，再从机身侧面绕到主板，不穿过任何零件 |
| 5.28–5.88 s | **微距 2**：推到主板，掠过主控芯片（QFP 鸥翼引脚 + 焊锡角）、内存（BGA 焊球）、阻容、电感、晶振、FPC 座；标注 05 主控芯片 / 06 内存 |
| 5.9–7.8 s | 镜头从侧面拉出到全景；倒序复位：快门叶片落下 → 快门、感光板、主板归位 → 镜头组逐组归位 → 光圈叶片回到全开 → 各组螺丝旋回 → 后壳、前壳、底盖、顶盖合上，毫米级落位回弹 |
| 7.8–8 s | 整机静置 |

底部中英说明字四段：拆开一台相机 / 光圈叶片收拢又张开 / 板上每颗元件都焊在自己的位置 / 再一层一层装回原位。

## 装配与无穿模设计
- 每个零件组只沿一条轴平移（±Y 光轴或 ±Z）；外层先拆、内层后拆，复位顺序相反。
- 光圈叶片最大外径小于光圈外壳内径；光圈外壳与光圈环同心不重叠；所有镜头组外径小于前壳开孔。
- 主板元件面与机芯后框之间留有间隙；软排线只在两板之间弯折。
- 标注与字幕不写任何尺寸或参数数值。

## 工具链与复现
- Blender 5.2.2 LTS（EEVEE，屏幕空间光追，AgX Medium High Contrast，40 TAA 采样，35 mm 镜头 + 景深）；相机不可见的柔光箱给金属与焊点提供长条高光；世界对相机是暗灰，对反射是灰度渐变。
- 模型单位为毫米，根节点缩放 0.01；运动全为确定性函数，无物理缓存。
- Python 3（numpy、Pillow）：`pcb_tex.py` 生成电路板贴图；`post.py` 做随 3D 锚点移动的引线标注（编号用 #FF6B3D）、说明字、暗角。
- FFmpeg（libx264 High, yuv420p, CRF 16）。

渲染约 15 分钟（M4，与 1–2 个其他渲染并行实测）+ 后期约 1 分钟 + 编码：

```bash
./render.sh <work_dir>
python3 <skill>/scripts/deliver.py --frames <work_dir>/frames --out clip.mp4
```

## 文件
- `pcb_tex.py`：电路板版图贴图与元件摆放表（`<board>_color.png / _rmh.png / _parts.json`）。
- `scene.py`：全部零件建模、材质、拆装时间线、软排线、相机路径、逐帧渲染与标注锚点 meta。
- `post.py`：标注、字幕、暗角。
- `render.sh`：一键复现。

## 已知限制
- 镜片是抛物面近似的回转体，不是按真实光学处方设计；EEVEE 屏幕空间折射对多枚镜片叠在一起时不如路径追踪准确。
- 元件是盒体 + 焊锡三角棱柱近似，没有真实元件的圆角塑封与引脚弯折半径；BGA 只建了外两圈焊球（内圈被芯片挡住看不到）。
- 九片叶片分层叠放（每片一层），相邻叶片在一处的上下叠放次序与真实光圈不同，正面看不出。
- 快门只有叶片开合，没有做驱动连杆。
- 无穿模依据是装配轴 / 时序 / 尺寸设计与抽帧审看，没有做逐帧几何碰撞检测。
- 微距景深较浅，芯片边缘之外的元件有意虚化。
- 两段微距转场（约 4.8 s、6.0 s）是镜头在高密度电路板前的快速连续运镜，自动 QA 把第 145–146、179–184 帧对标为跳变（帧差 31–38，全片均值 10.4，A 为 5.9）；抽帧确认是连续视差运动，无切镜、无零件穿过镜头、无黑帧。B 的整体运动量约为 A 的 1.8 倍。
